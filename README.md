# rsa-enc-plugin


# Encrypte the response payload for Kong

## Overview

The `rsa-enc-plugin` for Kong Gateway provides encryption functionalities for responses coming from backend.

## Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/ngaikwad28/rsa-enc-plugin.git
   cd rsa-enc-plugin.git

=========================================================================================
### 2. Install and Enable the Plugin

1. **Install the Plugin**

   If you have LuaRocks installed, navigate to the plugin directory and run:

   ```bash
   sudo luarocks make kong-plugin-rsa-enc-plugin-0.1.0-1.rockspec
